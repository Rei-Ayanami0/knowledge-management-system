# 知识管理系统

本地离线知识点、词汇、单选题与图片复习软件，可作为浏览器版使用，也可通过 Electron 打包为 Windows 桌面应用。

## 功能

- 复习本管理、学科筛选、长按拖拽排序与每轮复习数量设置
- 知识点、词汇、单选题和图片的导入、编辑、搜索、导出与批量删除
- 翻译练习、单选题答题反馈、随机抽题、重点复习与累计学习统计
- 右键选中文字加入任意复习本，并记住上次选择
- 图片本地存储、缩放显示、暗色模式、默认小写与直接删除等设置
- 离线词典自动补充常见英文词汇或短语释义

## 浏览器版

直接打开 `index.html` 或 `知识管理系统.html` 即可使用。浏览器版数据由浏览器本地存储保存；清理站点数据可能导致内容丢失。

## 桌面版开发与打包

```bash
npm install
npm start
npm run dist
```

桌面版使用 Electron。运行后的学习数据保存在 Windows 文档目录下的 `知识管理系统数据`，图片保存在同目录的 `images` 文件夹；不会因清理浏览器数据而丢失。
