# 复习本

一个无需安装的本地复习软件。双击 `index.html` 即可使用。

## 功能

- 复习本的新建、管理与删除
- 表格式知识点管理：题干 / 知识点、答案、操作
- 批量导入词汇：整段粘贴带编号的“英文 + 空格或制表符 + 中文”内容，自动逐条拆分保存
- 批量导入知识点：无分隔符时整行作为纯知识点保存；有 `|||` 或制表符时保存为知识点与答案；不会按空格切分，避免长知识点被截断
- 批量删除：勾选多条知识点后可一次删除
- 随机复习：先显示题面，点击后显示答案
- “重点复习”自动加入独立的错题本
- 黑白界面；数据只保存在本机浏览器中
- 离线自动释义：英文词汇或短语未填写答案时，从本地词典补充中文；未收录时提示且不保存

## 注意

首次打开时会自动生成 3 条示例内容。数据保存在浏览器本机存储中；清除浏览器对本页面的网站数据会删除已录入内容。

## 离线词典

软件附带的离线词典来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License）。查词全程不联网；词典覆盖大量常见英语词汇和词组，未收录的词汇或固定搭配会明确提示。
