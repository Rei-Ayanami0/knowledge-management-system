# 知识管理系统 · 全栈版

本分支已升级为本地全栈版本：Node.js 内置 HTTP 服务 + SQLite 数据库。无需安装第三方依赖。

## 启动

在本文件夹打开 PowerShell 后执行：

```powershell
npm start
```

再在浏览器访问 `http://localhost:3000`。首次打开请注册本地账号；数据库会自动创建为 `knowledge-system.sqlite`。

## 功能

- 本地账号注册、登录、密码哈希验证、退出登录
- 昵称、头像（emoji 或图片网址）修改
- SQLite 持久化：用户、复习本、题库与复习记录
- 复习本的新建、管理与删除
- 表格式知识点管理：题干 / 知识点、答案、操作
- 批量导入词汇：整段粘贴带编号的“英文 + 空格或制表符 + 中文”内容，自动逐条拆分保存
- 批量导入知识点：无分隔符时整行作为纯知识点保存；有 `|||` 或制表符时保存为知识点与答案；不会按空格切分，避免长知识点被截断
- 批量删除：勾选多条知识点后可一次删除
- 随机复习：先显示题面，点击后显示答案
- “重点复习”自动加入独立的错题本
- 五种内容：知识点、快速阅读、选择题、数学公式、数学题
- 批量导入五种内容，支持不限行数；自动去重
- 每轮随机抽取指定数量复习；记录正确和重点复习次数
- 黑白响应式界面，适配手机、平板和桌面浏览器
- 数据只保存在本机 SQLite 数据库中
- 离线自动释义：英文词汇或短语未填写答案时，从本地词典补充中文；未收录时提示且不保存

## 注意

首次打开时会自动生成 3 条示例内容。数据保存在浏览器本机存储中；清除浏览器对本页面的网站数据会删除已录入内容。
